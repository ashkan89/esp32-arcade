# Game Arcade game guide

Every game has twelve stages and a Campaign Complete ending. Clearing the last stage adds
5,000 points plus 1,000 per remaining life, once, and freezes the score. A replays; B returns
to the launcher. Menu/Back opens pause, restart, controls and exit. The HUD shows stage /12.

Bosses use the combat game's own damage and attack rules. Puzzle, territory and racing
games finish their normal objectives. Stages vary formations, enemy counts, armor, boards,
speed, deadlines or thresholds; these are compact native arcade campaigns, not hundreds
of individually authored narrative levels. The controls screen explains each game's buttons.
